# P2 information-gain plan: visual ROI and anatomical/context evidence

## 1. Locked research question

For CF005 components predicted as Fatty tissue esophagus (class 7) or Lymph node
(class 19), does evidence that is not a transform of the segmentation class
probabilities improve exact class-swap detection beyond P2-DENSE?

Two evidence families are admissible:

1. frozen visual ROI evidence from the RGB image and predicted component mask;
2. pre-specified, single-frame observable anatomical/context evidence.

No probability ratio, margin, class prior multiplier, temperature transform, or
logistic transform of the same probabilities counts as new information.

## 2. Frozen baseline

| Item | Frozen value |
|---|---|
| Cohort | 744 predicted class-7/19 components |
| Positives | 99 exact 7↔19 swaps |
| Cases | five OOF validation cases |
| Primary baseline | raw dense counterpart-class probability |
| Baseline macro-case AUPRC | **0.3737689693** |
| Baseline macro-case AUROC | 0.7677342440 |
| Test data | prohibited |
| Clinical authority | none |

P2-DENSE increased AUPRC by `+0.0260` over top-k P2 on 5/5 cases but did not
change operational warning sets at 5–30% target coverage. Therefore future work
must improve both ranking and, eventually, warning utility.

## 3. Common experimental protocol

### 3.1 Split and leakage control

- Outer evaluation: leave-one-case-out across the five OOF validation cases.
- The segmentation prediction for each case comes only from a model that held
  that case out.
- PCA, scaling, classifier fitting, threshold fitting, prototype construction,
  and relation envelopes use the four training cases only.
- GT is used only to assign the frozen evaluation target. It is never an input
  feature.
- The held-out test split remains unopened.

### 3.2 Mandatory outputs

- macro-case and per-case AUPRC/AUROC/Brier;
- paired delta over P2-DENSE for every case;
- descriptive case-bootstrap interval;
- direction-specific results for predicted 7 and predicted 19;
- tiny versus non-tiny results;
- tool-low/tool-high and evidence-available/evidence-unknown results;
- PPV/recall at training-fitted target coverage 5%, 10%, 20%, and 30%;
- feature/provenance manifest and negative-control results.

### 3.3 Exploratory information-gain gate

A new evidence family passes only if all conditions hold:

1. macro-case AUPRC delta over its matched P2 control is at least `+0.02`;
2. at least 4/5 held cases improve;
3. descriptive case-bootstrap lower bound for delta is above 0;
4. non-tiny AUPRC does not decrease by more than `0.01`;
5. improvement is not reproduced by geometry/direction or shuffled-evidence
   controls;
6. no material degradation of minimum-case PPV at 5% and 10% coverage.

For the asymmetric knowledge branch, K3 must clear these conditions against
both its matched direction control K2 and raw P2-DENSE. This guard is necessary
because adding direction can itself weaken P2; beating a weakened comparator
does not constitute information gain beyond P2.

This is an exploratory gate, not a clinical deployment gate. Warning deployment
still requires independent cases, clinical adjudication, and a separately frozen
safety threshold.

## 4. Branch V — frozen visual ROI evidence

### 4.1 Input contract

- Original RGB frame.
- OOF predicted component mask and bounding box.
- No GT mask, GT station, error label, or anatomy correction as encoder input.
- No inpainting or synthetic removal of instruments.
- Tool overlap is recorded for stratification/abstention only.

### 4.2 Primary representation

Use a frozen DINOv2 ViT-S/14 encoder. The existing five DINOv2 baselines used a
frozen encoder; encoder tensor hashes must be identical across folds before one
copy is reused.

For each component, export:

- mask-weighted mean patch embedding inside the component;
- context-ring mean embedding around the component;
- ROI-minus-ring contrast embedding;
- global CLS embedding as a context control;
- token support, bbox geometry, mask fill ratio, and tool overlap as audit fields.

Tiny masks that do not cover a patch do not disappear silently: use a deterministic
bbox-pooling fallback and emit `low_token_support=1`.

### 4.3 Visual ablation matrix

| ID | Features | Purpose |
|---|---|---|
| V0 | geometry/direction only | shortcut control |
| V1 | visual ROI only | visual separability |
| V2 | P2-DENSE learned control | matched classifier control |
| V3 | P2-DENSE + geometry | test geometry shortcut |
| **V4** | **P2-DENSE + visual ROI** | primary visual information-gain test |
| V5 | P2-DENSE + global CLS | global-frame versus local-ROI control |
| V6 | P2-DENSE + shuffled ROI | leakage/spurious-control test |
| V7 | P2-DENSE + ROI + ring contrast | local-context contribution |

Primary dimensionality reduction is PCA with 8 components, fitted inside each
outer training split, followed by class-balanced L2 logistic regression. The
number of PCA components and classifier settings remain fixed for this round;
no selection on held-case performance is allowed.

### 4.4 Interpretation

- V4 > V2, but V3 ≈ V4: gain is geometry, not appearance.
- V5 ≈ V4: gain is global station/case context, not ROI morphology.
- V6 improves: leakage or unstable shortcut must be investigated.
- V4 passes while controls fail: visual ROI contains candidate incremental
  information and can proceed to independent validation.

## 5. Branch K — anatomical/context evidence

### 5.1 Evidence policy

Only relations selected before performance inspection and observable from a
single frame can enter the primary context test. Missing partner anatomy is
`UNKNOWN`, never a violation. Instrument occlusion disables affected evidence;
the anatomy is not inpainted.

Station identity derived from filename or GT visibility is oracle-only and cannot
enter the deployable primary method.

### 5.2 CF005 primary relation

The current protocol-supported relation relevant to CF005 is:

```text
AA-018: Fatty tissue esophagus (7)
        attached_to_or_near
        Esophagus (6)
single-frame observability: yes
scope: annotation semantic
```

No equivalent clinically reviewed global relation for generic Lymph node (19)
is currently available. This makes the context test asymmetric and limits what
it can claim.

For each component, compute from OOF predictions:

- class-6 partner presence/evidence availability;
- normalized component-to-esophagus boundary distance;
- touch/contact indicator;
- fold-train AA-018 distance-envelope violation;
- fold-train expected-touch mismatch;
- direction-conditioned hypothesis compatibility;
- tool/uncertainty evidence gate.

### 5.3 Context ablation matrix

| ID | Features | Purpose |
|---|---|---|
| K0 | pair direction only | mandatory asymmetry control |
| K1 | AA-018 evidence only | knowledge-only test |
| K2 | P2-DENSE + direction | matched shortcut control |
| **K3** | **P2-DENSE + direction + AA-018** | primary knowledge gain |
| K4 | P2-DENSE + ungated AA-018 | gating contribution |
| K5 | P2-DENSE + station oracle | diagnostic upper bound, non-deployable |
| K6 | P2-DENSE + empirical 7–19 touch | AI-provisional sensitivity only |

K6 cannot support a knowledge claim: the 7–19 touch relation is empirical,
AI-provisional, and may encode annotation/station confounding.

### 5.4 Required conclusion language

- If K3 fails: AA-018 is anatomically meaningful but not predictive for this
  verifier endpoint under current observation quality.
- If K3 passes: AA-018 supplies exploratory incremental information; clinical
  review and independent validation are still required.
- A station-oracle gain does not authorize station inference or hard rules.

## 6. Joint branch

Run the joint model only after V4 or K3 independently passes its gate.

| ID | Features |
|---|---|
| J0 | P2-DENSE |
| J1 | P2-DENSE + winning visual family |
| J2 | P2-DENSE + winning knowledge family |
| J3 | P2-DENSE + visual + knowledge |

J3 must beat the stronger of J1/J2, not merely P2. Otherwise the two new evidence
families are redundant.

## 7. Stop rules

Stop or redesign when:

- visual gain is matched by geometry/global/shuffled controls;
- knowledge gain disappears after direction control;
- fewer than three held cases are evaluable for a stratum;
- a method improves mean AUPRC but worsens minimum-case PPV materially;
- evidence depends on GT station, GT anatomy, filename station, or test data;
- any preprocessing was selected after inspecting held-case labels.

Auto-correction and ontology-loss experiments remain locked regardless of an
exploratory V/K pass. They reopen only after an independently validated warning
module and clinical review.
